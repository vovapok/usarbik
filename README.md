# Linux vs Windows vs Mac OS

Сайт-гид по сравнению операционных систем: **Linux**, **Windows** и **macOS**. Таблицы, графики, плюсы и минусы каждой платформы.

## Страницы

| Файл | Описание |
| --- | --- |
| `index.html` | Главная: философия систем, цифры, график доли рынка, быстрое сравнение |
| `linux.html` | Плюсы/минусы Linux, таблица дистрибутивов, график, видео |
| `windows.html` | Плюсы/минусы Windows, история версий, график, видео |
| `macos.html` | Плюсы/минусы macOS, линейка Mac, график, видео |
| `comparison.html` | Сводная таблица на 12 критериев, 6 графиков, сценарии использования |

## Технологии

- Чистый **HTML5** / **CSS3** / **JavaScript** (без зависимостей)
- Шрифт [Inter](https://fonts.google.com/specimen/Inter) через Google Fonts
- Тёмная тема с дизайн-системой на CSS-переменных
- Адаптивная вёрстка (мобильное меню, брейкпоинты 768px / 480px)
- Анимированный фон: падающие 🐧 🪟 🍎 (генерируются в `script.js`)
- CSS-графики с анимацией при прокрутке (IntersectionObserver)

## Запуск

Просто откройте `index.html` в браузере, либо:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```
